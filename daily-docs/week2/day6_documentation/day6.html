📐 Week 2 – Day 6: Autodesk Fusion – Phone Stand & Cylindrical Engraving

📌 Some Basic Features of Autodesk Fusion

📱 Section 1: Creation of Mobile Stand Using Autodesk Fusion

Step 1

Select part design and click on Create.

Step 2

Select a plane.

Step 3

Click on Sketch to create a model.

Step 4

Create a rectangle of dimensions suitable for your smartphone.

Step 5

Select the shape and press E (Extrude), then adjust the distance as needed.

Step 6

Select the Text option from the Create menu.

Step 7

Select Revolve from Surface and choose the bottom axis to revolve the text at 45 degrees.

🥫 Section 2: How to Engrave Text on Cylindrical Objects

Step 1

Select part design and click on Create.

Step 2

Select a plane.

Step 3

Click on Sketch to create a model.

Step 4

Create a circle of diameter 100 mm.

Step 5

Select Extrude or press E and set thickness to 40 mm.

Step 6

Select the top surface and use the Shell command to hollow the object. Set thickness to 1 mm.

Step 7

Select the front plane and write the text.

Step 8

Select the text and extrude it. Set distance to -1 mm and choose Object from Start.

🎯 Conclusion

Using Autodesk Fusion for designing a phone stand and engraving text on a cylindrical object helps in learning important 3D modelling skills such as sketching, extruding, modifying shapes, and adding custom text. Fusion 360 provides an easy and accurate way to create both simple and complex models with professional results.

The phone stand project improves understanding of product design and measurements, while the cylindrical text engraving process demonstrates how to customize objects using sketch and emboss tools. Overall, Fusion 360 is a powerful and user‑friendly software for creating creative, precise, and practical 3D designs.
