📘 Day 1: GitHub – Introduction, Setup & First Commit

1. Introduction to GitHub

GitHub is a web-based platform used for version control and software development. It helps developers store, manage, track, and collaborate on coding projects.

2. Uses of GitHub

  • Store source code online
  • Track project changes
  • Collaborate with teams
  • Manage open-source projects
  • Backup important files

3. Purpose of GitHub

The main purpose of GitHub is to improve teamwork and project management in software development.

4. Installation & Usage Steps (with Screenshots)

Step 1 – Sign Up

Open GitHub website and click Sign Up.

Step 2 – Fill details & verify email

Step 3 – Download and install Git

Step 4 – GitHub Dashboard

Configure Git with Your Name & Email

Git needs to know who you are. Run these commands in Terminal / Command Prompt:

git config --global user.name "Your Full Name"
git config --global user.email "youremail@example.com"
git config --list

Create a Repository on GitHub

Step 1: Log in → Click your profile picture → Your repositories → New (green button).

Step 2: Fill in the repository form:

  • Repository name: my-first-project
  • Description (optional)
  • Select Public
  • Tick Add a README file

Step 3: Click Create repository

5. Open the Project in VS Code

Step 1: Open VS Code

Step 2: Click File → Open Folder

Step 3: Select a folder and open it

6. Push Files using VS Code Terminal

Step 1: Click on Terminal → New Terminal

Run the following Git commands in order:

git init
git status
git branch -M main
git commit -m "Initial commit"
git add .
git remote add origin https://github.com/your-username/your-repo-name.git
git push origin main --force

7. Check the Pushed Files

The files are successfully pushed to GitHub. Refresh your repository page to see them.

Conclusion

GitHub is an essential platform for developers to manage, share, and collaborate on projects.
