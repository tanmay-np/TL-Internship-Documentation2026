📘 Week 3 – Day 3: Firebase Setup & DHT11 Sensor with ESP32

📌 Introduction to Firebase

Firebase is a platform by Google that helps developers build, run, and grow web and mobile applications without managing much backend infrastructure.

🔧 How to Create & Use Firebase?

Step 1 – Search Firebase

Search Firebase on Google Chrome or Microsoft Edge.

Step 2 – Click on the link

Step 3 – Open console in another tab

Step 4 – Click "Get started"

Set up a Firebase project.

Step 5 – Type name for your project

Allow AI assistance – it helps during project by adding more details and ideas.

Step 6 – Click on Authentication

After creating the project, go to Authentication from Security.

Step 7 – Click "Get started"

Step 8 – Add sign-in method

Step 9 – Enable permission & enter email

Enter your email and save it.

Step 10 – Select Realtime Database

From Database and storage, select Realtime Database.

Step 11 – Click "Create database"

Step 12 – Select Singapore (or nearest location)

Step 13 – Select "Start in test mode"

Click Enable.

Step 14 – Database created

Step 15 – Go to Settings → General

Step 16 – Select Service accounts

Step 17 – Generate new private key

Select any Admin SDK configuration snippet and click Generate new private key.

Step 18 – Click on Database secrets

Step 19 – Copy the key

Step 20 – Go to General → General

Step 21 – Scroll down and select Web

Step 22 – Add nickname and register

Step 23 – Get API key

🖥️ Arduino IDE Setup

Step 24 – Open Arduino IDE

Step 25 – Select Board

Step 26 – Select COM port

Select COM3 (or your appropriate port).

Step 27 – Download ESP32 board support

Step 28 – Write the code

Write the given code in Arduino IDE.

Step 29 – Modify placeholders

  • WiFi_SSID → your mobile hotspot name
  • WiFi_password → your mobile hotspot password
  • Database URL → your Realtime Database URL
  • Database secret → your database secret

Step 30 – Connect DHT11 sensor

Take ESP32, three jumper wires, and DHT11. Connect as shown:

  • DHT11 VCC → ESP32 3.3V
  • DHT11 GND → ESP32 GND
  • DHT11 DATA → ESP32 GPIO pin (e.g., D4)

Step 31 – Run the program

Check the program and connections, then run it.

📌 Key Takeaways

  • Firebase provides Authentication, Realtime Database, and easy API integration.
  • ESP32 can connect to Firebase over Wi‑Fi to send sensor data.
  • DHT11 measures temperature and humidity – a common IoT sensor.
  • The circuit requires proper wiring (VCC, GND, data pin).
  • Always keep your database secrets and API keys secure.

🎯 Conclusion

Today we successfully set up a Firebase project, configured Authentication and Realtime Database, connected an ESP32 to Firebase, and interfaced a DHT11 sensor to send temperature/humidity data. This is a complete IoT pipeline – from hardware to cloud – and forms the basis for many real‑world monitoring projects.
