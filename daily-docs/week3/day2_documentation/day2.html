📘 Firebase Setup for LED Control

Documentation of Firebase on LED

Firebase is a platform by Google that helps developers build, run, and grow web and mobile applications without managing much backend infrastructure.

How to Create and Use Firebase?

  1. Step 1: Search Firebase on Google Chrome or Microsoft Edge.
  2. Step 2: Click on the link.
  3. Step 3: Open console in another tab.
  4. Step 4: Click Get started to set up a Firebase project.
  5. Step 5: Name your project. Allow AI assistance if desired.
  6. Step 6: Go to Authentication under Security.
  7. Step 7: Click Get started.
  8. Step 8: Add first sign-in method.
  9. Step 9: Enable permission, enter email and save.
  10. Step 10: Select Realtime Database.
  11. Step 11: Click Create database.
  12. Step 12: Choose region (e.g., Singapore).
  13. Step 13: Select Start in test mode and enable.
  14. Step 14: Database created.
  15. Step 15: Go to Settings → General.
  16. Step 16: Select Service accounts.
  17. Step 17: Generate new private key.
  18. Step 18: Click Database secrets.
  19. Step 19: Copy the key.
  20. Step 20: Back to General.
  21. Step 21: Scroll down and select Web.
  22. Step 22: Add app nickname and register.
  23. Step 23: Copy the API key.
  24. Step 24: Open Arduino IDE.
  25. Step 25: Select the correct Board.
  26. Step 26: Select the correct COM port.
  27. Step 27: Install ESP32 board support if needed.
  28. Step 28: Write the code in Arduino IDE.
  29. Step 29: Modify placeholders: WiFi_SSID, password, Database URL, secret, LED_PIN.

📌 Key Takeaways

  • Firebase provides backend services without managing servers.
  • Create project → enable Authentication → Realtime Database → get API keys.
  • ESP32 connects to Firebase over Wi‑Fi to control an LED remotely.
  • Keep secrets and keys secure.
