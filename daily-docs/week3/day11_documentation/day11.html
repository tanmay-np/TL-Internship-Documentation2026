Sensors, Actuators, Physical AI & Embedded Systems

Internship documentation: advanced concepts in robotics, edge computing, microcontrollers and control theory.

📌 Objective

To understand the integration of Physical AI systems where artificial intelligence meets hardware: sensors, actuators, microcontrollers, and real-time control. This session covered edge computing architectures, PID control fundamentals, microcontroller ecosystems (Arduino, ESP32), and industrial actuation. The goal is to build a strong foundation for robotics and smart automation projects at Tinkerers' Lab.

⚙️ Core Topics

Physical AI

Physical AI = AI Models + Sensors + Actuators + Control Systems — the foundation of embodied intelligence. It powers autonomous vehicles, smart manufacturing, and next‑gen robotics.

Sensors Processor / AI Model Decision → Control Actuator Physical Action
Autonomous Vehicles
Smart Manufacturing
Embodied AI

Microcontroller

Built-in RAM, I/O, low power, embedded applications (Arduino, ESP32).

Processor (MPU)

High computing power, external RAM/ROM, runs OS (computers, smartphones).

Edge Computing

Processing data near the source → low latency, faster response, privacy. Sensor → Edge Device → Action (bypass cloud).

Sensor → Edge Device → Actuator VS Sensor → Cloud → Actuator

Control Systems (P, PI, PID)

P – Proportional (reduces error)
PI – Proportional + Integral (steady‑state accuracy)
PID – Adds Derivative (predictive, smooth response)

Widely used in robotics, drones, industrial automation.

🔵 Active Sensors

Require external power, emit energy. Ex: Ultrasonic, Radar, IR.

🟢 Passive Sensors

No external excitation, detect natural energy. Ex: LDR, Thermistor, Photodiode.

Actuators (Electrical → Motion)

⚙️ DC Motor ⚙️ AC Motor ⚙️ Servo Motor ⚙️ Stepper Motor ⚙️ BLDC Motor ⚙️ Harmonic Drive

Servo motors give precise position control — essential for robotic arms.

Arduino Nano/Uno/Mega

ATmega328P, beginner-friendly, huge community. Ideal for sensor interfacing.

ESP32

Dual core, WiFi, BLE, high processing power — perfect for IoT and edge AI.

MOSFET

Metal Oxide Semiconductor Field Effect Transistor — high‑speed switching device used in motor drivers, power supplies, and embedded electronics. Essential for PWM control of actuators.

Cisco Systems

Global leader in networking hardware (routers, switches), cybersecurity, and industrial IoT infrastructure. Their solutions enable robust edge computing and industrial communication.

📄 Microcontroller Datasheets

Arduino Uno (ATmega328P)

Microcontroller: ATmega328P
Operating Voltage: 5V
Input Voltage: 7-12V
Digital I/O Pins: 14 (6 PWM)
Analog Inputs: 6
Clock Speed: 16 MHz
Flash: 32 KB
SRAM: 2 KB, EEPROM: 1 KB
Protocols: UART, I2C, SPI

ESP32

CPU: Xtensa LX6 dual core
Clock Speed: up to 240 MHz
Wi-Fi: 802.11 b/g/n
Bluetooth: BLE + Classic
GPIO Pins: 34 (multipurpose)
ADC: 12‑bit, 18 channels
DAC / PWM / Touch sensors
RAM: 520 KB SRAM, Flash: 4 MB
Protocols: I2C, SPI, UART, CAN
